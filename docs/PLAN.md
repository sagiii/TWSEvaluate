# TWS評価アプリ (Android) 実装プラン・進捗記録

このファイルはリポジトリ管理下の設計・進捗ドキュメント。元になった対話ベースのプラン(`~/.claude/plans/`配下、Claude Code管理領域)の内容をここに集約し、以後の進捗はここを更新していく。

## Context

店頭でTWS(完全ワイヤレスイヤホン)を選ぶ際、Bluetoothオーディオのプロファイル(A2DP=音楽再生と、HFP/SCO=会議通話)で挙動が大きく変わる。店頭では通話相手がいない・毎回条件が揃わないため、A2DPとHFPの両方を同じ手順で素早く・公平に試せるツールが無い、という課題がある。

このアプリは、1台のイヤホンにつき1回の「評価セッション」の中で、音楽再生(A2DP)と会議通話を模したBluetooth SCO/HFP接続でのマイク録音+リアルタイムモニタを行き来しながら試し、後から製品ごとに聞き比べられる記録(録画・録音)を残すことを目的とする。

すり合わせで判明した要件:
- 会議シナリオは「録音して後で聞き比べる」ことが主目的。同時に自分の声を**2秒遅延**させてイヤホンにモニタ再生する機能も欲しい。
- テスト風景の録画は、動画の音声トラックが「TWSのマイクで拾った音声そのもの」になっていると価値が高い(将来的な理想。Phase 1bで対応予定)。
- Spotify連携は複雑なので一旦スコープ外(omit)。同梱音源+端末内音源選択のみでよい。
- 製品名のテキスト入力は店頭で面倒。評価開始時にパッケージ/値札をカメラで1枚撮影し、それをサムネイル兼ラベルにする方式を採用(テキスト入力は無し)。
- 音楽再生と会議を画面で切り分けず、1回の評価(録画)の中でシームレスに行き来したい → 1つの評価セッション画面に🎵/🎤トグルを置く統合UI。
- 評価中にメーカー純正アプリ(ANC/ノイキャン切替など)へ一時的に切り替えても、音声(録音・再生・Bluetooth接続)は裏で継続してほしい。動画は最悪黒フレーム/セグメント分割になってもOK。

## 画面設計

### 画面1: セッション一覧 (ホーム)
```
┌─────────────────────────────┐
│  TWS評価                 ＋  │ ← ＋で新規評価開始
├─────────────────────────────┤
│ [写真] 2026/09/28 14:32      │
│        🎵🎤  ●REC 03:12      │ ← 使ったモードのアイコンと録画有無

```
サムネイルは各セッション開始時に撮った商品写真。製品名テキストは持たない。タップでセッション詳細画面へ。

### 画面2: 新規評価セッション (メイン画面)
起動直後、カメラが全画面で開きパッケージ/値札を撮影 → 即座に評価セッション画面へ遷移し、同時に裏で動画録画が自動的に始まる。

```
┌─────────────────────────────┐
│ [商品写真]  ●REC 00:47   ✕  │
├─────────────────────────────┤
│   🎵 音楽        🎤 会議     │ ← セグメントトグル
├─────────────────────────────┤
│  [🎵] ジャンル選択/再生/A2DP接続表示        │
│  [🎤] SCO接続状態/自声モニタON-OFF/レベルメーター │
├─────────────────────────────┤
│     [ 評価を終了して保存 ]    │
└─────────────────────────────┘
```
モード切替は🎵/🎤トグル1本。切り替えるとBluetoothプロファイルが自動追従(音楽→A2DP、会議→SCO/HFP)。モード区間はタイムラインとして記録。

## バックグラウンド動作の実現方針

- **音声(マイク録音・音楽/遅延モニタ再生・Bluetooth SCO/A2DP接続)**: `EvaluationSessionService`(`microphone` + `mediaPlayback`タイプのForeground Service)に集約。Activityの表示状態に依存せず、サービスが生きている限り継続する。
- **動画録画**: Android のカメラアクセス制限により、バックグラウンドに回るとCameraXのライフサイクル連動でカメラが解放される。1本の動画に黒フレームを焼き込む高度な合成は行わず、前面復帰のたびに新しいセグメントとして録画を再開する方式(`video_0.mp4`, `video_1.mp4`, ...)を採用。

## 録画は会議モード中のみ(2026-09-29変更)
当初は評価セッション全体(音楽モードも含め)を通して録画していたが、音楽モード中の映像は
音声が無音になるだけで情報量が無く、尺が伸びがちという指摘を受け、**会議モードに入っている
間だけ録画する**方式に変更した。`switchTo()`で会議モードに入るタイミングで録画開始、抜ける
タイミングで録画終了(`videoRecorder.stopFinal`)するようにした。これにより動画区間と会議録音
区間がほぼ1:1で対応するようになり、Phase 1bの音声差し替え処理も実質的にシンプルな1区間
マッチになった(バックグラウンドで録画が途切れた場合のみ1テイクに複数動画が対応する)。
セッション詳細画面もこれに合わせて、録画リストと会議録音リストを別々に出す代わりに
「会議1」「会議2」…と**テイクごとに動画+波形付き音声をまとめたカード**で表示するよう変更した
(`SessionDetailScreen`の`ConferenceTakeCard`)。

**実機検証(Pixel 6a, 2026-09-28)**: 撮影→音楽/会議切替→保存→詳細再生の一連の流れをクラッシュなく確認。保存された`video_0.mp4`(H.264/AAC)と`conference_0.wav`(PCM 16kHz mono)をffprobeで検証し、いずれも正常に完結したファイルであることを確認済み。Bluetooth SCO経由のマイク録音(87秒分の実データ)が機能していることも確認。

### Phase 1b: 動画への会議音声焼き込み — ✅ 完了・実機検証済み
- [x] `ConferenceVideoMuxer`を実装。動画区間の音声トラックを、その時間帯に重なる会議録音(WAV)から合成したPCM(会議録音が無い時間帯=音楽モードは無音)に差し替え、AAC再エンコード+動画トラックはコピーのままMediaMuxerで多重化
- [x] `EvaluationSessionScreen`に動画区間・会議録音区間それぞれの絶対経過時間(開始/終了)を記録し、評価終了時に重なりのある動画区間だけミックスするよう配線
- [x] `finish()`の二重実行ガード追加(実機テストでモードタイムラインが重複するバグを発見・修正)

**実機検証(Pixel 6a, 2026-09-29)**: 生成された`mixed_video_0.mp4`をffprobe/silencedetectで検証。0〜8.2秒(音楽モード区間)は無音、8.2〜94秒(会議モード区間)に実際の会議録音が正しく時間軸を合わせて焼き込まれていることを確認済み。

## 同梱BGM(2026-09-29追加、同日中にPixabay音源へ差し替え)
端末に音楽ファイルが無いテスト環境でも音楽モードを試せるよう、10ジャンル x 3曲 = 30曲を同梱。
最初は手続き的に合成した仮音源(`tools/generate_bundled_music.py`)を入れたが、
ユーザー希望により[Pixabay Music](https://pixabay.com/music/)の実在の高品質音源(Pixabay
Content License: 無料・クレジット表記不要・改変可・アプリ組み込み可)に差し替え済み。
出典一覧・ライセンス詳細は`docs/MUSIC_CREDITS.md`を参照。
- ジャンル: ポップ/ロック/ジャズ/クラシック/EDM/Lo-fi/アンビエント/ヒップホップ/
  アコースティック/ボサノバ
- フル尺のまま同梱(ユーザー希望、トリミングなし)。ラウドネス正規化+AAC 192kbps変換済み。
  APKサイズは同梱音源だけで約120MB
- 手続き生成の仮音源に戻したい場合は`tools/generate_bundled_music.py`を参照
- UIは`EvaluationSessionScreen`の音楽モードにジャンルチップ+曲番号ボタンとして実装
  (`BundledTracks.kt`)。端末内ファイル選択と併用可能。

## 開発環境メモ
- Android SDK: `~/Library/Android/sdk` (platforms: android-35, android-36)
- ビルド時、システムのデフォルトJDKが25系だとGradle 8.9と非互換のため、`JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home` を指定して`./gradlew assembleDebug`を実行すること
- 実機インストール: `adb`は`~/Library/Android/sdk/platform-tools/adb`
- リポジトリ: `git@github.com:sagiii/TWSEvaluate.git`
